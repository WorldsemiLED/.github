Worldsemi

Next-Generation Addressable LED Technology

Worldsemi develops addressable LEDs and LED driver IC technologies for engineers, makers, developers, and product designers.

What We Focus On

* Native 3.3V MCU logic compatibility
* Ultra-low standby current
* Miniature addressable LED pixels
* RGB and RGBW digital LEDs
* High-refresh digital LED solutions
* ESP32, Arduino and FastLED applications
* Open hardware and developer projects
